## 7. Performance Baseline

- **fib(30)**: compile 9ms, run <1s
- **100×100 nested loops + struct methods**: compile+run 57ms
- **Compile-time complexity**: O(n²) worst case (Resolve + MIR lower + Driver writeback)
- **Runtime performance**: Good (LLVM -O3 via LLVMSysEmitter)
- **8 optimizations identified** for v0.2 (3 done, 5 deferred)

## 8. Known Limitations (v0.1)

### P0 — NONE (all fixed) ✅

### P1 (partially addressed)
- HP-1: Sound Copy detection — infrastructure ready, activation deferred (v0.1 has no #[derive(Copy)])
- ~1,462 LOC region_inference.rs — partially used (4 functions called, rest is v0.2 infrastructure)
- 8 writeback passes — documented, consolidation deferred to v0.2

### P2 (feature completeness, deferred to v0.2+)
- For-loop over arrays, open ranges, trait default body cross-trait calls
- `Box<T>` not in prelude
- GAP-2/3/4: region/drop/lifetime infrastructure
- GAP-7: disjoint closure captures
- GAP-9: no real stdlib
- GAP-14: cross-module visibility
- GAP-15: mini-cargo CLI
- GAP-16: `landin test`/`fmt`/`doc` subcommands
