## 1. Executive Summary

v0.4 builds on the v0.3 release (Task 11 monomorphization + Task 14 object
safety) to add the remaining type system features needed for a complete
Rust-like language: associated types, where clauses, and improved error
messages.

## 3. v0.4 Remaining Tasks

### 3.1 Task 17: Associated Types ✅ COMPLETE (Stages 16.67-16.69)

**Goal**: `type Item;` in trait definitions, with resolution in impl blocks.

**Dependency**: Task 11 (✅ complete)

**Phases**:
1. **Phase 1**: AST + HIR parsing of `type Item;` in traits
2. **Phase 2**: MIR representation — `TyKind::Projection(def_id, substs)` for `<T as Iterator>::Item`
3. **Phase 3**: Type resolution — resolve associated types during typeck
4. **Phase 4**: Codegen — emit concrete types for resolved projections

**Estimated stages**: 4-6 stages

### 3.2 Task 14 Phase 3: Supertrait Object Safety (P2)

**Goal**: `trait T: Sized` makes T non-object-safe. `trait T: Super` requires
Super to also be object-safe.

**Dependency**: Task 14 Phase 1+2 (✅ complete)

**Estimated stages**: 1-2 stages

### 3.3 Where Clauses (P2)

**Goal**: `fn f<T>() where T: Clone + Debug` — where clause support in
generic functions and impl blocks.

**Dependency**: Task 11 (✅ complete)

**Estimated stages**: 2-3 stages

### 3.4 Improved Error Messages (P3)

**Goal**: Better error messages for:
- Type mismatch (show expected vs found)
- Borrow checker errors (show borrow lifetime)
- Trait bound not satisfied (show which bound, which type)

**Estimated stages**: 2-3 stages

### 3.5 Performance Optimization (P3)

**Goal**: Profile and optimize compilation pipeline:
- MIR lowering (current bottleneck for large programs)
- Type checking (unification table could be more efficient)
- Codegen (MonoLayoutMap building could be cached)

**Estimated stages**: 2-3 stages
