## 3. v0.5 Tasks

### 3.1 Trait Solver (P1, 6-8 stages)

**Goal**: Implement trait bound inference for type parameters. Currently,
`fn f<T>() where T: Clone` is a declarative constraint (not checked at
compile time). The trait solver will verify these constraints during
typeck by checking if the concrete type (at monomorphization time)
satisfies all bounds.

**Phases**:
1. **Phase 1**: Data structures — `TraitPredicate`, `Goal`, `InferCtxt`
2. **Phase 2**: Unification-based solving — `evaluate_goal`
3. **Phase 3**: Where clause integration — feed where clauses as assumptions
4. **Phase 4**: Supertrait expansion — automatically derive supertrait bounds
5. **Phase 5**: Error reporting — "trait bound not satisfied" errors
6. **Phase 6**: Tests + integration

**Dependency**: None (builds on existing TraitResolver)

### 3.2 CodegenError Error System (P1, 2-3 stages)

**Goal**: Replace codegen panics with proper `CodegenError` propagation.
`run_codegen_pipeline` returns `CodegenResult<()>` instead of `()`.

**Phases**:
1. **Phase 1**: Define `CodegenError { message, span }` type
2. **Phase 2**: Migrate ~40 `unwrap()` calls in `llvm/mod.rs` to `?` operator
3. **Phase 3**: Update public API (`codegen_crate` / `codegen_crate_to_module`)

**Dependency**: None

### 3.3 GATs — Generic Associated Types (P2, 4-6 stages)

**Goal**: `type Item<T>;` in trait definitions, with resolution in impl blocks.

**Dependency**: Trait Solver (for bound checking on associated type bounds)

### 3.4 Trait Coherence Enhancement (P2, 2-3 stages)

**Goal**: Orphan rule enforcement + overlap detection improvement.

**Dependency**: None

### 3.5 MIR Optimization Passes (P3, 3-4 stages)

**Goal**: Const propagation, dead code elimination, simple constant folding.

**Dependency**: None

### 3.6 Incremental Compilation (P3, 4-6 stages)

**Goal**: Only recompile changed items. Track dependencies between items.

**Dependency**: MIR Optimization Passes (for cache key stability)

### 3.7 Cross-compilation (P3, 2-3 stages)

**Goal**: Target triple configuration, cross-compile to different architectures.

**Dependency**: None
