## 6. v0.2 Risk Register

| Risk | Probability | Impact | Mitigation |
|------|------------|--------|------------|
| Ty interning breaks all pattern matches | HIGH | HIGH | Do first, update all matches in one pass |
| Monomorphization causes code bloat | MEDIUM | MEDIUM | Implement with shared code for same-type-erased |
| NLL fixpoint has performance regression | MEDIUM | LOW | Keep single-pass as fallback |
| Drop elaboration interacts with borrowck | HIGH | HIGH | Implement after NLL fixpoint is stable |
| EmitValue refactor breaks codegen | HIGH | HIGH | Do independently, keep old path as fallback |

## 7. v0.2 Success Criteria

1. **Monomorphization works**: `Vec<i32>::new()` produces correct code
2. **Lifetimes enforced**: `&'a T` with mismatched lifetimes is rejected
3. **Drop works**: `impl Drop for File` runs destructor at scope end
4. **Closures work everywhere**: closures in if-branches, match arms, return values
5. **Cross-module visibility**: `pub fn` is accessible, `fn` is not
6. **No P0 soundness bugs**: all v0.2 features are sound
7. **Performance**: compile-time regression < 2× v0.1 baseline
8. **Test coverage**: 6500+ conformance tests, 2500+ Rust tests, all passing
