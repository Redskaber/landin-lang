## 1. v0.3 Goal (per `12-roadmap.md`)

**v0.3 = Stage 1 重写完成 + 自举验证**: 43-64 月 (远期)

Stage 1 = 用 Landin 重写编译器自身, 至少完成 lexer + parser + AST.
自举验证 = Stage 1 通过 Stage 0 的同一套 conformance suite (5026 tests).

## 2. Stage 1 Rewrite Plan

### Phase 1: Lexer (月 11)
- Port `src/lexer/` (6 modules) from Rust to Landin
- Target: tokenize all 5026 conformance .lin files correctly
- Key challenge: Landin lacks `enum` with data variants in compile pipeline (Stage 0 limitation)

### Phase 2: Parser (月 12)
- Port `src/parser/` (8 modules) from Rust to Landin
- Target: parse all 5026 conformance .lin files correctly
- Key challenge: Pratt parser needs closures (not callable in Stage 0 compile pipeline)

### Phase 3: HIR + Resolve (月 13)
- Port `src/hir/` + `src/resolve/` from Rust to Landin
- Target: resolve all names in conformance tests

### Phase 4: MIR + Typeck + Borrowck (月 14)
- Port `src/mir/` + `src/typeck/` + `src/borrowck/` from Rust to Landin
- Target: type-check + borrow-check all conformance tests

### Phase 5: Codegen + Self-host (月 15)
- Port `src/codegen/` from Rust to Landin
- Target: compile Landin compiler source with Landin compiler (self-hosting!)
- Verify: Stage 1 passes same 5026 conformance tests (behavior consistency per §5.2)

## 3. Key Dependencies (Stage 0 → Stage 1)

| Stage 0 Feature | Stage 1 Need | Status |
|----------------|-------------|--------|
| Closures callable | Parser needs Pratt closures | ❌ Stage 0 limitation |
| Generic functions | Compiler uses generics heavily | ❌ Stage 0 limitation |
| Trait impls | TraitResolver uses traits | ❌ Stage 0 limitation |
| if-let / while-let | Some parser code | ❌ Stage 1 feature |
| Inner attributes | Crate-level attrs | ❌ Stage 1 feature |
| ?Sized bound | Some type patterns | ❌ v0.2 feature |
| HRTB (for<'a>) | Trait resolution | ❌ Stage 0 limitation |

**Critical path**: Must fix closures/generics/traits in Stage 0 compile pipeline
before Stage 1 rewrite can begin.

## 4. Risk Assessment

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Stage 0 limitations block Stage 1 | High | Fix closures/generics/traits first |
| Conformance suite insufficient | Medium | Continue expanding edge cases |
| Performance of Landin-compiled Landin | Medium | Optimize codegen |
| Bootstrap circular dependency | Low | Use Stage 0 binary to compile Stage 1 |

## 5. Recommended Next Steps

1. **Stage 0 compile pipeline fixes** — Fix closures/generics/traits in compile pipeline
   (currently ~300 FAIL tests document these limitations)
2. **Conformance expansion** — Continue adding edge-case tests
3. **Stage 1 prototype** — Start with lexer port as proof of concept
4. **mini-cargo** — Build system for multi-crate Landin projects
