## 4. Feature Summary

### v0.2 Features (completed in Stage 8)
- Lifetime elision (§3.2, RFC #141)
- Object safety (§2.3, RFC #255)
- extern "C" ABI (§13.2)
- Drop elaboration (§5)
- async/await foundation (§10, MVP synchronous)

### Compiler Pipeline
- Lexer: hand-written, 6 modules, maximal munch
- Parser: recursive descent + Pratt, 8 modules
- HIR: lowering + name resolution, 7 modules
- MIR: type inference + NLL borrow checker + region inference
- Codegen: LLVM IR via Emitter trait, 5 modules
- Traits: TraitResolver + vtable + dyn Trait + stdlib

### CLI
- `--emit-tokens`: token stream output
- `--emit-ast`: AST summary
- `--compile`: full pipeline (lex→codegen)
- `--emit-llvm-ir`: LLVM IR output

## 5. Known Limitations (Stage 0)

~300+ documented limitations via FAIL conformance tests:
- Closures not callable in compile pipeline
- Generic functions/impls not fully supported in compile
- if-let / while-let are Stage 1 features
- Inner attributes #![...] are Stage 1 features
- ?Sized and HRTB not supported
- Various typeck/borrowck edge cases

All limitations are documented as FAIL tests in the conformance suite,
providing a clear executable specification for Stage 1 re-implementation.
