## 3. v0.6 Tasks

### 3.1 macro_rules! System (P1, 6-8 stages)

**Goal**: Implement `macro_rules!` declarative macro system. This is the
prerequisite for println! 通解化 (removing the 4-layer 特解).

**Phases**:
1. **Phase 1**: Macro definition parsing — `macro_rules! name { ... }`
2. **Phase 2**: Macro expansion infrastructure — token tree matching + substitution
3. **Phase 3**: Pattern matching — `$name:expr`, `$name:ty`, `$name:ident`
4. **Phase 4**: Repetition — `$(...)*`, `$(...)+`, `$(...)?`
5. **Phase 5**: Built-in macros migration — println!/assert!/vec! → macro_rules!
6. **Phase 6**: Hygiene — basic macro hygiene (no accidental capture)
7. **Phase 7**: Tests + integration

**Dependency**: None

### 3.2 GATs — Generic Associated Types (P2, 4-6 stages)

**Goal**: `type Item<T>;` in trait definitions, with resolution in impl blocks.

**Dependency**: Trait Solver ✅

### 3.3 Incremental Compilation (P2, 4-6 stages)

**Goal**: Only recompile changed items. Track dependencies between items.

**Dependency**: MIR Optimization ✅ (for cache key stability)

### 3.4 Cross-compilation (P3, 2-3 stages)

**Goal**: Target triple configuration, cross-compile to different architectures.

**Dependency**: None
