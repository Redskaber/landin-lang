## 2. Stage 0 Known Limitations

### Type System

| Limitation | Impact | Fix Plan |
|-----------|--------|---------|
| ~~Param unify unsound~~ | ~~Generic type params unify with any type~~ | ✅ Stage 18.98 (Adt substs checked) |
| **Deref on non-Ref** | Pattern bindings on `&self` don't propagate reference types | v0.2 reference type tracking |
| **`LocalId(0)` fallback** | Non-Local borrowed places in region constraints | v0.2 field projection regions |

### Code Generation

| Limitation | Impact | Fix Plan |
|-----------|--------|---------|
| ~~MIR optimization not wired~~ | ~~DCE + const_prop implemented but not called~~ | ✅ Stage 18.96 wired (DCE → const_prop → DCE) |
| **Single-file compilation** | No project/crate system | v0.2 mini-cargo |
| **No incremental compilation** | Full recompile every time | v0.2 (requires project system) |
| **BinaryOp2 fallback** | Range expressions in codegen produce "0" with warning | v0.2 CodegenResult propagation |

### Platform Support

| Limitation | Impact | Fix Plan |
|-----------|--------|---------|
| **Linux only** | No Windows/macOS target triples | v0.2 cross-compile expansion |
| **No ABI diversity** | Only `extern "C"` tested | v0.2 `extern "system"`, `extern "Rust"` |

### Standard Library

| Limitation | Impact | Fix Plan |
|-----------|--------|---------|
| **Facade only** | String/Vec/Option/Result are type stubs, not real implementations | v0.2 full stdlib |
| **No `format!`/`write!`** | Only `println!`/`print!`/`eprintln!`/`eprint!` | v0.2 format macros |
