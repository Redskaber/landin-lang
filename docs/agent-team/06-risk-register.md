## 当前风险

### RISK-001：NLL 算法实现超期

- **报告 Agent**：ALG-B
- **报告日期**：2026-07-18
- **等级**：R1
- **类别**：技术
- **描述**：NLL 算法（universal region + type tests + SCC 压缩）实现复杂度可能超预期 1 个月
- **影响**：阻塞 borrow check 模块，延迟 stage 0 完成
- **概率**：中
- **缓解方案**：降级 1——回退到 lexical lifetime（节省 3-4 月）；降级 2——简化 NLL（仅 forward dataflow）
- **执行者**：ALG-B + DEV-B
- **状态**：待处理（月 6 评估）

### RISK-002：Stage 0 工作量超期

- **报告 Agent**：PM-B
- **报告日期**：2026-07-18
- **等级**：R1
- **类别**：进度
- **描述**：Stage 0 实际需 130-180k 行 Rust，1 人全职需 27-40 月
- **影响**：v0.1 发布延迟
- **概率**：高
- **缓解方案**：严格 scope 控制；砍 async/closures 之外的非必需；6 级降级方案
- **执行者**：PM-A + PL-A
- **状态**：处理中

### RISK-004：rustc MIR 持续演化导致文档过时

- **报告 Agent**：PM-B
- **等级**：R2

- **描述**：Landin 名称虽零冲突，但未来可能被挑战

- **报告 Agent**：PM-A
- **等级**：R2
